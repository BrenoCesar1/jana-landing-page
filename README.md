# Jana Santos — Consultora de Imagem & Coach de Estilo

Site institucional de Jana Santos, Coach de Estilo e Consultora de Imagem.

## Estrutura do Projeto

```
Projeto jana/
├── index.html              # Página principal
├── assets/
│   ├── css/
│   │   └── main.css        # Estilos customizados (animações, botão WhatsApp etc.)
│   ├── js/
│   │   └── main.js         # Scripts (scroll reveal, navbar behavior)
│   └── images/
│       ├── hero.jpeg       # Foto principal (seção hero)
│       ├── look-01.jpeg    # Portfólio — Look blazer cinza
│       ├── look-02.jpeg    # Portfólio — Look blusa branca
│       └── look-03.jpeg    # Portfólio — Look colete bege
└── README.md
```

## Tecnologias

| Tecnologia       | Uso                                      |
|------------------|------------------------------------------|
| HTML5            | Estrutura semântica da página            |
| Tailwind CSS CDN | Utilitários de estilo (classes inline)   |
| CSS customizado  | Animações, botão flutuante WhatsApp      |
| JavaScript puro  | Scroll reveal + efeito scroll no navbar  |
| Google Fonts     | Playfair Display + Inter                 |
| Font Awesome 6   | Ícones                                   |

## Como rodar localmente

Abra o `index.html` diretamente no navegador, ou use um servidor local como o **Live Server** (extensão do VS Code) para evitar restrições de CORS com arquivos locais.

```bash
# Com Live Server (VS Code)
# Clique com o botão direito em index.html → "Open with Live Server"

# Com Python
python3 -m http.server 8080
# Acesse: http://localhost:8080
```
